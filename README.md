# 🏥 Clinic Management System API

## 🚀 Overview
Backend system for managing clinic operations including patients, doctors, appointments, and billing.

---

## ✨ Features
- 🔐 Authentication & Authorization (JWT)
- 👨‍⚕️ Doctor Management
- 🧑‍🦱 Patient Management
- 📅 Appointment Scheduling
- 💰 Billing System
- 📊 Admin Control Panel APIs

---

## 🛠 Tech Stack
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- AutoMapper
- JWT Authentication

---

## 🧱 Architecture
- Clean Architecture
- Repository Pattern
- DTO Pattern

3. Run migrations
4. Start API
